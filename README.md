# iPhone Duo — a field note

An unofficial, static showcase for iPhone Duo, the newest iPhone in stores as of 20 November 2026. The page is an original editorial layout: Fraunces and Atkinson Hyperlegible, a CSS 3D model that unfolds on scroll, and figures taken from Apple’s public pages. It does not use Apple’s product photography or marketing lines.

Open `site/index.html` in a browser, or from this folder:

```bash
python3 -m http.server 4173 --directory site
```

GitHub Pages publishes the `site` directory from `main` to [https://s3nafps.github.io/iphone-showcase/](https://s3nafps.github.io/iphone-showcase/). Paths are relative, so they resolve under that project path. In the repository settings, Pages should use GitHub Actions as the source.
